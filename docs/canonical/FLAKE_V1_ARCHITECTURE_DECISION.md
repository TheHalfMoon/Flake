## Authority

The authoritative architecture contract is in the canonical build plan, especially sections 6, 12, 15, 18, 20, 21, 24, 25, 31–35, and the task contracts.

The frozen v1 direction is a local-first continuity product with Rust owning the correctness/security/data boundary, an established transactional canonical store, deterministic resolution, rebuildable derived indexes, complete portable export, and replaceable external agents exchanging bounded evidence packages and reviewable proposals.

Mandatory graph/model infrastructure, rich collaborative editing, generalized cloud sync, execution brokerage, marketplace/plugin expansion, and hosted AI dependencies are outside the v1 dependency graph unless a later authorized ADR reopens them.

Any implementation-time discovery that would change a Class C architecture decision must stop the affected unit and follow the ADR/review rule defined by the canonical plan.
