# T03-07 artifact family — local continuity proof preregistration

Plan contract: `docs/canonical/FLAKE_CANONICAL_BUILD_PLAN.md` section 26 ("P03 value gate before desktop") and the `T03-07` task row. This directory is sealed preregistration material for a study that has not yet recruited any participant — see `docs/evidence/flake-v1/T03-07/REPORT.md` for the exact completion disposition.

| Artifact | Path | Description |
|---|---|---|
| Protocol | `PROTOCOL.md` | The frozen preregistration protocol: research question, eligibility, recruitment, consent, budgets, success/failure/timeout/exclusion definitions, allocation, analysis plan, decision routing |
| Consent/privacy package | `CONSENT.md` | Exact participant-facing consent and privacy material |
| Case generator | `generate_cases.py` | Deterministic generator; reproducible from `MASTER_SEED`/`DEV_SEED` |
| Confirmatory case bank (sealed, held out) | `cases_confirmatory.json` | 96 disjoint cases, one per (participant, pair, role) cell |
| Dev/synthetic case pool (never confirmatory) | `cases_dev.json` | 8 cases, used only for training and the dry run |
| Allocation mechanism | `allocation.py` | Pure functions: case-role mapping, condition order, presentation order |
| Allocation generator | `generate_allocation.py` | Writes the reconstructable `allocation_confirmatory.json` |
| Allocation table | `allocation_confirmatory.json` | Full 48-row table plus counterbalance summary |
| Raw run manifest / harness | `harness.py` | Append-only, resumable `.jsonl` record reader/writer with schema validation |
| Analysis (producer) | `analysis.py` | Preregistered metrics and mechanical Pass/Fail/Inconclusive routing |
| Independent verification (oracle) | `verify_independent.py` | Separately written recomputation, never imports `analysis.py` |
| Synthetic dry run | `dry_run.py` | End-to-end machinery exercise using only dev/synthetic cases |
| Sealing | `seal.py` | Computes and records SHA-256 digests of every load-bearing artifact plus the exact product commit/tree |
| Seal record | `SEALS.json` | Output of `seal.py`, generated once all sealed files are final |
| Tests | `test_cases.py`, `test_allocation.py`, `test_harness.py`, `test_analysis.py`, `test_verify_independent.py`, `test_dry_run.py`, `test_protocol.py` | V01/V05/V09/V15 protocol/dry-run validation, synthetic non-evaluation cases only |
| Test aggregator | `run_tests.py` | Runs every `test_*.py` and reports a combined exit code |

## What has not happened

No participant has been recruited. No confirmatory attempt has been run. `runs/confirmatory/` does not exist until a real session produces it. `runs/dry-run/` is disposable demonstration output regenerated by `dry_run.py` on every invocation — it is never read by the confirmatory analysis path (`analysis.py`'s `forbid_case_source="dev_synthetic"` guard makes this a hard failure if attempted, not a convention).

## Reconstructing everything from the seed alone

```bash
python3 generate_cases.py        # -> cases_confirmatory.json, cases_dev.json (byte-identical to sealed copies)
python3 generate_allocation.py   # -> allocation_confirmatory.json (byte-identical to sealed copy)
python3 dry_run.py               # -> runs/dry-run/records.jsonl + PASS/FAIL agreement report
python3 run_tests.py             # -> all seven suites
python3 seal.py                  # -> SEALS.json (recomputes digests; compare to the sealed copy)
```
